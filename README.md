# BLUW Wedding Quiz & Bingo Platform 💍🥂

แพลตฟอร์มสร้างและจัดกิจกรรมเกมอินเทอร์แอคทีฟสำหรับ **งานแต่งงาน (Wedding Reception / After Party)** และ **งานสัมมนา (Seminar / Corporate Event)** ออกแบบมาเพื่อ **นายพิธี (Wedding MC)** ทั้งสำหรับนำไปใช้ในงานพิธีของตนเอง และ **ออกรหัสแพ็กเกจขายเกม (Client License Code)** ให้บ่าวสาวหรือผู้จัดงานนำไปเปิดเล่นเองได้ทันที

---

## ✨ ฟีเจอร์หลักครบทุกความต้องการ

1. **เลือกสร้างเกมได้ทั้ง 2 รูปแบบหลัก (ในระบบเดียว)**
   - **โหมดที่ 1: Kahoot-Style Speed Quiz (เกมตอบคำถามชิงความไว)**
     - คำถาม 4 ตัวเลือก คิดคะแนนความถูกต้อง + โบนัสความไว (Speed Bonus)
     - หน้าจอโปรเจกเตอร์แสดงเวลานับถอยหลัง จำนวนแขกที่ตอบแล้ว กราฟแท่งเฉลยแต่ละตัวเลือก และ Leaderboard Top 5
   - **โหมดที่ 2: Wedding Bingo (รูปแบบใหม่ 2 สไตล์ให้เลือก)**
     - **2.1 บิงโกคำถามบ่าวสาว (Couple Quiz Bingo)**: นำคำถามเกี่ยวกับบ่าวสาวมาใช้ เมื่อแขกตอบถูกจะได้รับตราประทับลงบนกระดานบิงโกบนมือถือ
       - เลือกได้ทั้งแบบ **"ตอบถูกแล้วเรียงช่องไปเรื่อยๆ ตามลำดับ (Sequential Fill)"** หรือ **"สุ่มตำแหน่งคำตอบบนกระดานของแขกแต่ละคน (Randomized Card)"**
       - เลือกขนาดตารางได้ `3x3 (9 ช่อง)`, `4x4 (16 ช่อง)`, หรือ `5x5 (25 ช่อง มีช่อง FREE ตรงกลาง)`
     - **2.2 บิงโกตัวเลข / คำมงคล (Classic Number Bingo)**: หมุนวงล้อสุ่มตัวเลข (1-25, 1-50, 1-75 หรือคำศัพท์มงคล) บนหน้าจอเวที แขกกดแตะเลขบนมือถือ ระบบตรวจแถวชนะบิงโกอัตโนมัติแบบเรียลไทม์

2. **การออกเกมเป็น QR Code & ห้องรอเริ่มเกม (Waiting Lobby)**
   - ออก **QR Code ขนาดใหญ่คมชัด** พร้อมรหัสห้อง PIN 6 หลัก ให้แขกใช้กล้องมือถือหรือ LINE สแกนเข้าเล่นได้ทันทีโดยไม่ต้องโหลดแอป
   - **รองรับผู้เล่นพร้อมกัน 200 คน/ห้อง**
   - ช่วงรอเริ่มเกม หน้าจอโปรเจกเตอร์จะแสดงจำนวนผู้เข้าร่วมสดๆ พร้อมการ์ดชื่อเล่น อวตาร และหมายเลขโต๊ะของแขกเด้งขึ้นหน้าจอทันทีก่อนกดเริ่มเกม

3. **ระบบหลังบ้านนายพิธี & รายงานครบถ้วน (Admin Backoffice & Reports)**
   - แดชบอร์ดสรุป **จำนวนเกมทั้งหมด**, **จำนวนรอบการเล่นสะสม**, **จำนวนแขกเข้าร่วมสะสม**, และ **รหัสแพ็กเกจลูกค้า**
   - **ประวัติการเล่นและรายงานย้อนหลัง**: ดูอันดับผู้ชนะ คะแนนรายบุคคล คำอวยพรบ่าวสาวจากแขก และปุ่ม **ดาวน์โหลดรายงานเป็นไฟล์ CSV** ส่งมอบให้บ่าวสาวเก็บเป็นที่ระลึก
   - **พอร์ทัลสำหรับลูกค้าที่ซื้อเกม (Client Package Portal)**: เกมทุกชุดมีรหัส `Client Code` และปุ่มคัดลอกลิงก์เฉพาะงาน (`?client=รหัสลูกค้า`) สำหรับส่งให้ลูกค้าที่ซื้อเกมนำไปเปิดหน้าจอโปรเจกเตอร์ในงานของตนเองได้โดยไม่เห็นข้อมูลหลังบ้านของงานอื่น

## 🚀 วิธีติดตั้งและเชื่อม Supabase ฟรี + Vercel ฟรี

### ขั้นตอนที่ 1: ตั้งค่า Supabase (ฟรี)
1. ไปที่ [Supabase](https://supabase.com/) สร้างโปรเจกต์ใหม่ (Free Tier รองรับ Realtime 200 concurrent connections)
2. ไปที่เมนู **SQL Editor** ใน Supabase แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ [`supabase/schema.sql`](./supabase/schema.sql) (หรือคัดลอกจากปุ่ม **"ตั้งค่า Supabase"** มุมขวาบนของหน้าเว็บ) ไปกด **Run**
3. ไปที่เมนู **Project Settings -> API** คัดลอกค่า:
   - `Project URL` (`VITE_SUPABASE_URL`)
   - `anon public key` (`VITE_SUPABASE_ANON_KEY`)

### ขั้นตอนที่ 2: นำขึ้น Vercel (ฟรี)
1. เข้าเว็บ [Vercel](https://vercel.com/) แล้วกด **Add New Project** เลือก Repository `jeerapan411/BluwWeddingQuizgame` จาก GitHub
2. ในส่วน **Environment Variables** ให้ใส่ค่า:
   - `VITE_SUPABASE_URL` = Project URL จาก Supabase
   - `VITE_SUPABASE_ANON_KEY` = Anon Key จาก Supabase
   *(หมายเหตุ: สามารถกรอกตั้งค่าผ่านปุ่ม "ตั้งค่า Supabase" บนหน้าเว็บได้โดยตรงเช่นกัน)*
3. กด **Deploy** ก็พร้อมใช้งานสแกน QR Code ในงานแต่งและงานสัมมนาได้ทันที!
